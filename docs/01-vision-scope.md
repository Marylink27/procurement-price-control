# 1. Видение и границы

## Контекст

Розничная сеть (18 магазинов, около 10 000 активных SKU, импортные напитки, снеки, непродовольственные товары) закупает у нескольких десятков поставщиков. Поставщики меняют цены без единого графика и присылают прайс-листы в своих форматах: Excel с разной структурой, CSV, иногда таблицей в теле письма.

Сейчас закупщик вручную находит изменения, сравнивает их с ценами в 1С через ВПР, согласует рост цены с руководителем в мессенджере и вносит новые цены в 1С руками.

## Проблема

| Симптом | Последствие |
|---|---|
| Сопоставление позиций поставщика с каталогом вручную по названию | часы работы на каждый прайс, ошибки на похожих позициях (вкусы, объёмы) |
| Сравнение цен через ВПР по выгрузке | пропущенный рост цены уходит в себестоимость, маржа падает незаметно |
| Согласование в мессенджере | нет истории: кто и почему согласовал рост цены, вопрос «откуда эта цена» не закрыть |
| Ручной ввод в 1С | опечатки в цене, задержка: в 1С остаётся старая цена, пока закупщик не дошёл до прайса |

## Цели и метрики

Метрики задают целевые значения для приёмки; базовые значения замеряются на пилоте по 3 поставщикам.

| ID | Цель | Метрика | Целевое значение |
|---|---|---|---|
| M-1 | Быстрее обновлять цены | время от получения прайса до цены в 1С | не больше 1 рабочего дня для 90% прайсов |
| M-2 | Меньше ручной работы | доля позиций, сопоставленных автоматически | не меньше 85% со второго прайса поставщика |
| M-3 | Контроль роста цены | доля изменений выше порога, прошедших согласование | 100% |
| M-4 | Без ошибок ввода | расхождения между согласованной ценой и ценой в 1С | 0 |
| M-5 | Прозрачность | по любой цене видно, кто и когда её согласовал | для 100% цен, загруженных через портал |

## Стейкхолдеры

| Роль | Интерес | Участие |
|---|---|---|
| Закупщик (менеджер по закупкам) | меньше рутины, понятная очередь задач | основной пользователь, интервью, приёмка UI |
| Руководитель направления закупок | контроль роста цен и маржи | согласует рост выше порога, утверждает пороги |
| Категорийный менеджер | актуальная себестоимость для расчёта РРЦ | потребитель данных, отчёты |
| Поставщик | быстрее принятые цены, понятные ошибки в файле | загружает прайсы, исправляет ошибки |
| Администратор 1С | надёжный обмен без ручных правок | согласует формат обмена, сопровождает загрузку |
| Собственник | маржа сети | спонсор, утверждает цели |

## Границы

**Входит в проект:**

- загрузка прайсов: через портал, почтовый ящик импорта, API для крупных поставщиков;
- настройка шаблонов разбора файла по каждому источнику;
- автоматическое и ручное сопоставление позиций с каталогом, список исключённых позиций;
- расчёт отклонения от текущей закупочной цены, маршрутизация по порогам категорий;
- согласование в два уровня: закупщик, руководитель;
- выгрузка согласованных цен в 1С и приём результата загрузки;
- история цен и решений, сводка по поставщикам.

**Не входит (кандидаты на следующие этапы):**

- формирование заказов поставщику;
- расчёт розничных цен (РРЦ) и переоценка в магазинах;
- электронный документооборот с поставщиками, подписание спецификаций;
- мониторинг цен конкурентов.

## Допущения и ограничения

- Мастер-данные номенклатуры и штрихкодов ведутся в 1С; портал хранит их копию и обновляет её из 1С.
- Закупочная цена в 1С одна на пару «товар + поставщик» и действует с даты.
- Цены в прайсах с НДС; если источник присылает без НДС, это настраивается в шаблоне источника.
- Портал не меняет цены в 1С напрямую в базе: только через обработку обмена на стороне 1С.

## Глоссарий

| Термин | Значение |
|---|---|
| Прайс-лист | файл поставщика с ценами на его позиции |
| Источник | канал и шаблон, по которым приходит прайс конкретного поставщика |
| Позиция поставщика | строка каталога поставщика: его артикул, ШК, название |
| Товар каталога | номенклатура сети в 1С |
| Сопоставление | связь позиции поставщика с товаром каталога |
| Предложение | новая цена по позиции из конкретной загрузки прайса |
| Отклонение | (новая цена - текущая закупочная) / текущая закупочная × 100% |
| Порог автоприёма | рост цены, до которого предложение принимается без участия людей |
| Порог руководителя | рост цены, выше которого нужно согласование руководителя |
| Исключённая позиция | позиция поставщика, которую не нужно сопоставлять (оборудование, промо-материалы) |
