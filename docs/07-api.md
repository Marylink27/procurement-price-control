# 7. API

Спецификация OpenAPI 3.0: [`api/openapi.yaml`](../api/openapi.yaml). Открыть и попробовать: вставить файл в [editor.swagger.io](https://editor.swagger.io). Спецификация проходит `redocly lint` без ошибок.

## Ресурсы

| Метод | Путь | Что делает | Use case | Роли |
|---|---|---|---|---|
| POST | `/imports` | загрузить прайс | UC-01 | поставщик (свои источники), закупщик, админ |
| GET | `/imports/{id}` | статус и итоги загрузки | UC-01 | те же |
| GET | `/imports/{id}/errors` | ошибки строк | UC-01 | те же |
| GET | `/matches/unmatched` | позиции без пары с подсказками | UC-02 | закупщик |
| POST | `/matches` | ручное сопоставление | UC-02 | закупщик, админ |
| POST | `/exclusions` | исключить позицию | UC-02 | закупщик, админ |
| GET | `/offers` | очередь предложений с фильтрами | UC-03, UC-04 | закупщик, руководитель |
| POST | `/offers/{id}/decision` | решение по предложению | UC-03, UC-04 | закупщик, руководитель |
| POST | `/offers/decisions` | массовое решение | UC-03 | закупщик |
| GET | `/dictionaries/{name}` | справочник с ETag | UC-07 | все авторизованные |
| PUT | `/sync/{name}` | изменения справочника из 1С | UC-07 | сервисный токен 1С |
| POST | `/exports` | выгрузка в 1С вручную | UC-05 | закупщик, админ |

## Соглашения

- **Ошибки** в едином формате `{code, message, details}`: `code` для фронтенда и логов, `message` можно показать пользователю как есть.
- **Пагинация** курсорная (`limit`, `cursor`): очередь предложений меняется во время просмотра, смещение по номеру страницы давало бы пропуски и дубли.
- **Конкурентные решения:** если двое открыли одно предложение, второе решение получает `409` и актуальный статус, а не перезаписывает первое.
- **Асинхронный импорт:** `POST /imports` отвечает `202` сразу после приёма файла, разбор идёт в фоне, клиент опрашивает `GET /imports/{id}`. Большой прайс (10 000+ строк) не упирается в таймаут HTTP.
- **Справочники** отдаются по версии через `ETag` / `If-None-Match`: при неизменной версии `304` без тела (NFR-01).
